標籤用來描述探測器，選擇器則依據標籤決定每個檢查在哪裡執行。

## 標記探測器

標籤是附加在探測器上的鍵值組合。建議使用少量且一致的詞彙：

| 用途           | 範例                     |
| -------------- | ------------------------ |
| 地理區域       | `region=tw`              |
| 網路邊界       | `network=office`         |
| 基礎設施供應商 | `provider=aws`           |
| 環境           | `environment=production` |

使用穩定事實，不要使用暫時狀態。例如 `region=tw` 是有用的標籤，`healthy=true` 則不是。

## 為檢查挑選探測器

建立或編輯檢查時，選擇器會定義哪些已啟用的探測器執行它。選擇器可以符合一個或多個標籤條件。

空白選擇器會符合專案中所有已啟用的探測器。小型專案使用很方便，但新增大量探測器前請仔細檢查，因為檢查會展開到每個探測器。

## 指派生命週期

控制器會從目前設定推導有效指派：

```text
check selector + enabled probe labels -> effective assignment
```

探測器會向控制器輪詢指派。變更不會直接推送給 Agent，因此判斷結果前至少等待一個指派更新週期。

以下操作會重新計算指派：

- 建立、編輯、啟用、停用或刪除檢查。
- 新增、變更或移除探測器標籤。
- 啟用或停用探測器。

## 規劃標籤變更

重新命名或移除廣泛使用的標籤前：

1. 找出選擇器使用該標籤的檢查。
2. 在探測器加入替代標籤。
3. 更新受影響的選擇器。
4. 確認預期探測器已送達結果。
5. 移除舊標籤。

這個順序可避免指派中斷。

## 排查缺少的指派

若檢查沒有在預期探測器執行，請確認：

- 檢查已啟用。
- 探測器已啟用且上線。
- 每個選擇器條件都符合探測器目前標籤。
- 探測器已在最後一次變更後更新指派。
- 目標可從該探測器的網路連線。

公開狀態頁面可能顯示與所選檢查相關的探測器名稱與位置。標籤應具備維運意義，但不要放入密鑰或敏感內部拓撲。

確認選擇器預覽後，[建立檢查](/zh-TW/docs/guides/checks/)並驗證所有預期探測器都有提交結果。
