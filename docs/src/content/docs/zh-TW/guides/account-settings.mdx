帳號設定控制你在整個 Netstamp 站台中的身分與憑證，和專案成員資格及系統管理員權限彼此分開。

## 個人資料與電子郵件

在帳號設定中更新顯示名稱與個人資料。電子郵件地址用於識別登入帳號、邀請與驗證流程。

若站台要求驗證電子郵件，請開啟收到的驗證連結。變更或尚未驗證的地址可能影響密碼復原與專案邀請。

## 密碼

支援密碼驗證的帳號可以從安全性設定變更密碼。請使用唯一密碼並保存在密碼管理器。

只透過外部身分供應商建立的帳號，在站台允許設定以前可能沒有本機密碼。

## 已連結身分

Netstamp 可以把通用 OIDC、Google 與 GitHub 等外部身分連結到既有帳號。請在登入目標 Netstamp 帳號後進行連結，讓供應商登入能回到同一帳號。

解除連結前，先確認另一種登入方式正常。Netstamp 會阻止移除最後一個可用驗證方式。

## 工作階段

工作階段檢視會列出目前登入與近期驗證資訊。請撤銷不認得或不再使用的工作階段。

預設情況下，工作階段會在閒置 24 小時後到期，且最長不會超過 7 天。管理員可以修改全站的兩項限制。

若懷疑憑證外洩，請變更或輪替受影響的憑證，並撤銷其他工作階段。

## 個人 API 權杖

個人 API 權杖讓 Script 能以你的帳號呼叫 Netstamp API。建立權杖時：

1. 使用明確對應用途的名稱。
2. 只選取整合所需的權限範圍；目前的專案角色限制仍會套用。
3. 選擇符合用途的最短到期時間。
4. 立即複製權杖並存入 Secret Manager。

完整權杖只在建立時顯示一次。請撤銷未使用或外洩的權杖，且不要寫入原始碼或圖片。

## 停用帳號

停用前，先移交專案所有權與依賴該帳號的自動化憑證。Netstamp 不允許變更導致專案沒有擁有者，或站台失去必要管理員。

全站使用者復原與存取政策請參閱[系統管理](/zh-TW/docs/guides/system-administration/)。
