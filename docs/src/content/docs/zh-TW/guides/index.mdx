這些指南涵蓋 Netstamp 的日常工作流程，從整理專案到公開服務健康狀態。

## 建立監控

1. [建立專案並邀請成員](/zh-TW/docs/guides/projects-and-members/)。
2. 在你想觀察的網路中[註冊探測器](/zh-TW/docs/guides/probes/)。
3. [加入標籤與選擇器](/zh-TW/docs/guides/labels-and-assignments/)，控制檢查在哪裡執行。
4. [建立 Ping、TCP、HTTP 或 Traceroute 檢查](/zh-TW/docs/guides/checks/)。

## 調查與回應

- 從[分析概覽](/zh-TW/docs/guides/results-and-insight/)開始選取指派、控制時間並分享可重現的檢視。
- [分析 Ping、TCP 與 HTTP 結果](/zh-TW/docs/guides/results-and-insight/analyze-measurements/)，區分路徑、連接埠與應用程式問題。
- [調查 Traceroute 結果](/zh-TW/docs/guides/results-and-insight/investigate-traceroute/)，比較拓樸與單次執行。
- 建立[警示規則並調查事件](/zh-TW/docs/guides/alerts-and-incidents/)。
- 連接[通知目的地](/zh-TW/docs/guides/notifications/)以傳送到外部服務。
- 用[狀態頁面](/zh-TW/docs/guides/status-pages/)公開經過挑選的健康資訊。

## 管理存取權

- [帳號設定](/zh-TW/docs/guides/account-settings/)涵蓋個人資料、身分、工作階段、密碼與 API 權杖。
- [系統管理](/zh-TW/docs/guides/system-administration/)涵蓋整個站台的存取、使用者、管理員與驗證設定。

如果你還不熟悉資源模型，請先閱讀[核心概念](/zh-TW/docs/getting-started/core-concepts/)。
