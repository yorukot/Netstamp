專案會把一個監控環境與協作者放在一起。探測器、檢查、警示規則、通知目的地、事件與狀態頁面都屬於專案。

## 建立專案

開啟專案切換器並選擇**建立專案**。輸入容易辨識的名稱，並在介面提供時設定穩定的網址代稱。

網址代稱 會用在專案網址中。請使用小寫字母、數字與連字號；分享專案連結後，應避免修改。

建立專案的帳號會成為第一位擁有者。

## 切換專案

使用應用程式標頭中的專案切換器移動到其他專案。目前選取的專案會決定整個應用程式顯示哪些資源。

若頁面看起來沒有資料，請先確認是否選到正確的專案。

## 邀請成員

1. 開啟**專案設定**。
2. 進入成員區段。
3. 輸入對方的電子郵件地址並選擇角色。
4. 傳送邀請。

邀請只會授予所選專案的權限。收件人必須用被邀請的電子郵件地址登入後才能接受。

## 專案角色

| 角色   | 適用情境                                 |
| ------ | ---------------------------------------- |
| 擁有者 | 完整控制專案，包括所有權與刪除決策       |
| 管理員 | 管理專案設定與成員，但不含擁有者專屬操作 |
| 編輯者 | 建立與更新監控資源                       |
| 檢視者 | 讀取專案設定、結果與事件                 |

正式環境的專案建議至少保留兩位擁有者。Netstamp 會阻止移除或降級最後一位擁有者，以免專案失去管理者。

## 變更或移除存取權

擁有者與具權限的管理員可以在專案設定中更新成員角色或移除成員。當職責改變時，請重新檢視權限，尤其是能編輯檢查、警示規則或通知密鑰的帳號。

專案成員資格與系統管理彼此分開。系統管理員可以管理 Netstamp 站台，但仍需要成為專案成員才能操作專案資源。

## 更新或刪除專案

在**專案設定**修改專案中繼資料。修改網址代稱會更動專案網址，已儲存的連結可能失效。

只有擁有者應該刪除專案。刪除會移除專案及相關監控設定與資料，因此請先匯出或備份需要保留的內容。
