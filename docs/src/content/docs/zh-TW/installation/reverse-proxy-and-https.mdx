正式環境的 Netstamp 應使用單一且穩定的 HTTPS 來源。由反向代理終止 TLS，再把完整來源轉送到控制器。

## 設定公開來源

對外開放服務前先設定：

```dotenv
APP_ENV=production
PUBLIC_BASE_URL=https://netstamp.example.com
NETSTAMP_VERSION=<tested tag or digest>
```

`PUBLIC_BASE_URL` 是 OAuth 與 OIDC Callback、電子郵件與瀏覽器連結、OpenAPI、通知，以及控制器提供的探測器安裝程式所共用的唯一來源。它只能包含 HTTPS Scheme 與 Host，不得包含 Path、Query、Fragment 或憑證。

使用 `APP_ENV=production` 時，Session Cookie 會套用 `__Host-` Prefix、`Secure`、`HttpOnly`、`SameSite=Strict` 與 `Path=/`。使用者必須透過 HTTPS 存取應用程式。

## 轉送必要 Header

反向代理必須保留：

- `Host`
- `X-Forwarded-Proto`
- `X-Forwarded-For`
- Proxy 有提供時的 `X-Real-IP`
- `Authorization`

Nginx Server Block 範例：

```nginx
server {
    listen 443 ssl http2;
    server_name netstamp.example.com;

    ssl_certificate /etc/letsencrypt/live/netstamp.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/netstamp.example.com/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Authorization $http_authorization;
    }
}
```

將一般 HTTP 重新導向到相同的 HTTPS 來源。

## 限制直接存取控制器

反向代理與 Netstamp 位於同一主機時，將 Compose Port 綁定到 Loopback：

```yaml
services:
  netstamp:
    ports:
      - "127.0.0.1:3000:8080"
```

若 Netstamp 必須信任 Proxy 提供的 Client Address，請把 `HTTP_TRUSTED_PROXIES` 設為 Proxy 的確切位址或 CIDR Prefix，並以逗號分隔。除非不受信任的網路完全無法連到控制器 Port，否則不要信任所有位址。

## 網路方向

控制器需要：

- 接收來自瀏覽器、API Client 與探測器的 HTTPS 連線。
- 對外連線到已設定的 OAuth/OIDC Provider 與通知端點。
- 啟用電子郵件時可對外連線到 SMTP。
- 存取 PostgreSQL 資料庫。

探測器會主動向控制器建立 HTTPS 連線；控制器不需要連入探測器主機。

## 驗證公開部署

```bash
curl --fail https://netstamp.example.com/healthz
curl --fail https://netstamp.example.com/api/v1/healthz
curl --fail https://netstamp.example.com/api/v1/openapi.json >/dev/null
curl --fail https://netstamp.example.com/api/v1/install/agent.sh >/dev/null
```

另外確認 HTTP 會重新導向 HTTPS、憑證鏈有效、登入會設定安全 Cookie，且拋棄式探測器能連到公開來源。

## 正式環境檢查清單

- [ ] 已設定 `APP_ENV=production`。
- [ ] `PUBLIC_BASE_URL` 與公開 HTTPS 來源完全相同。
- [ ] 所有開發用密鑰都已分別替換。
- [ ] Netstamp 與 TimescaleDB Image 版本已固定。
- [ ] 資料庫與控制器 Port 未對外公開。
- [ ] Trusted Proxy 範圍沒有超出必要範圍。
- [ ] 兩個 Health Endpoint 都有監控。
- [ ] 已在測試環境成功還原資料庫備份。

廣泛開放帳號建立前，繼續設定[身分驗證與電子郵件](/zh-TW/docs/installation/authentication-and-email/)。
