Netstamp 的設定來自三個位置：

1. **部署設定**透過環境變數控制控制器、資料庫、公開來源、密鑰與背景工作；變更後必須重新啟動控制器。
2. **系統設定**在執行期間控制存取政策、電子郵件與外部身分供應商。
3. **建置設定**會把公開的分析工具與文件數值編譯進網頁資源。

請依設定的管理位置修改。執行期設定無法覆寫部署設定；修改既有容器的建置變數，也不會重新編譯前端。

## 部署設定

控制器會讀取環境變數，以及工作目錄或 `server/` 中選填的 `.env`。環境變數的優先順序高於 `.env`；Docker Compose 會讀取專案的 `.env`，並把支援的值傳入容器。

時間長度使用 Go 語法，例如 `250ms`、`5s`、`30m` 或 `168h`；布林值使用 `true` 或 `false`。密鑰必須穩定、彼此獨立，並排除在版本控制外。

Release `.env.example` 包含必要密鑰與正式環境 URL 設定。只需從本頁加入需要覆寫的項目。

## 執行期系統設定

可在 Netstamp 執行期間修改的設定，會由控制器保存於 **系統管理 → 系統設定**：

| 區段   | 執行期設定                                                    |
| ------ | ------------------------------------------------------------- |
| Access | 帳號建立、電子郵件驗證、專案建立與憑證變更                    |
| SMTP   | 郵件伺服器、寄件人、TLS、逾時與加密憑證                       |
| OIDC   | 通用 OpenID Connect Provider 與加密 Client Secret             |
| Google | Google Provider、Hosted Domain Allowlist 與加密 Client Secret |
| GitHub | GitHub Provider 與註冊行為                                    |

SMTP 與供應商憑證會使用 `SYSTEM_SETTINGS_ENCRYPTION_KEY` 加密。網站分析屬於建置設定，不在管理介面中設定。

## Compose 變數

| 變數                | 預設值                              | 用途                                |
| ------------------- | ----------------------------------- | ----------------------------------- |
| `NETSTAMP_IMAGE`    | `yorukot/netstamp`                  | 控制器 Image Repository             |
| `NETSTAMP_VERSION`  | `latest`                            | 控制器與 Migration Image Tag        |
| `TIMESCALEDB_IMAGE` | `timescale/timescaledb:2.20.3-pg16` | Database Image                      |
| `NETSTAMP_PORT`     | `3000`                              | 發布到控制器 Port 8080 的 Host Port |

正式環境請固定 Image 版本。Compose Volume 的邏輯名稱為 `netstamp-postgres`。

## 控制器核心

| 變數                             | 預設值             | 用途                                                           |
| -------------------------------- | ------------------ | -------------------------------------------------------------- |
| `APP_ENV`                        | `local`            | Runtime 環境；非本機會啟用安全的 Session Cookie 行為           |
| `DEMO_MODE`                      | `false`            | 啟用 Backend Demo 限制                                         |
| `SERVICE_NAME`                   | `controller`       | 日誌與 Telemetry 使用的 Service Identity                       |
| `APP_VERSION`                    | `0.1.0`            | 回報版本；Compose 會在此映射 `NETSTAMP_VERSION`                |
| `API_VERSION`                    | `v1`               | 掛載於 `/api/<version>` 的版本區段                             |
| `LOG_LEVEL`                      | `info`             | `debug`、`info`、`warn`、`error`、`dpanic`、`panic` 或 `fatal` |
| `LOG_PSEUDONYM_KEY`              | 開發用 Placeholder | 將敏感日誌識別碼假名化的穩定 Key                               |
| `SYSTEM_SETTINGS_ENCRYPTION_KEY` | 開發用 Placeholder | 加密已保存管理密鑰設定的穩定 Key                               |
| `SHUTDOWN_TIMEOUT`               | `10s`              | 控制器 Graceful Shutdown Deadline                              |

每個非本機部署都必須將資料庫密碼與四個應用程式 Key 替換為至少 32 字元的獨立隨機值。

## HTTP 與公開 Origin

| 變數                       | 預設值  | 用途                                                          |
| -------------------------- | ------- | ------------------------------------------------------------- |
| `PUBLIC_BASE_URL`          | 空白    | Callback、連結、OpenAPI 與探測器 Installer 使用的公開 Origin  |
| `HTTP_ADDR`                | `:8080` | 控制器 Listen Address                                         |
| `WEB_DIR`                  | 空白    | 編譯後的 Frontend Directory；Production Image 設為 `/app/web` |
| `REQUEST_TIMEOUT`          | `10s`   | Request Context Timeout                                       |
| `HTTP_READ_HEADER_TIMEOUT` | `5s`    | Header Read Timeout                                           |
| `HTTP_READ_TIMEOUT`        | `15s`   | Request Read Timeout                                          |
| `HTTP_WRITE_TIMEOUT`       | `15s`   | Response Write Timeout                                        |
| `HTTP_IDLE_TIMEOUT`        | `60s`   | Keep-alive Idle Timeout                                       |
| `HTTP_TRUSTED_PROXIES`     | 空白    | 逗號分隔的 Proxy IP 或 CIDR Prefix                            |

`PUBLIC_BASE_URL` 只能包含 Scheme 與 Host。非本機環境必須設定，Production 必須使用 HTTPS。

## 資料庫

| 變數                    | 預設值      | 用途                                     |
| ----------------------- | ----------- | ---------------------------------------- |
| `DATABASE_HOST`         | `localhost` | PostgreSQL Host；Compose 使用 `postgres` |
| `DATABASE_PORT`         | `5432`      | PostgreSQL Port                          |
| `DATABASE_USER`         | `netstamp`  | Database User                            |
| `DATABASE_PASSWORD`     | `netstamp`  | Database Password                        |
| `DATABASE_NAME`         | `netstamp`  | Database Name                            |
| `DATABASE_SSLMODE`      | `disable`   | PostgreSQL SSL Mode                      |
| `DB_MAX_CONNS`          | `10`        | Connection Pool 最大大小                 |
| `DB_MIN_CONNS`          | `0`         | Connection Pool 最小 Idle 數             |
| `DB_MAX_CONN_LIFETIME`  | `1h`        | Pool Connection 最大生命週期             |
| `DB_MAX_CONN_IDLE_TIME` | `30m`       | Pool Connection 最大 Idle 時間           |

Database Traffic 經過不受信任網路時請使用 TLS 驗證。標準 Compose Stack 會將其保留在私有 Compose Network。

## Session、密碼與 Token

| 變數                                    | 預設值             | 用途                                  |
| --------------------------------------- | ------------------ | ------------------------------------- |
| `AUTH_SESSION_HASH_KEY`                 | 開發用 Placeholder | Opaque Session Token 的 HMAC/Hash Key |
| `AUTH_API_TOKEN_HASH_KEY`               | 開發用 Placeholder | 個人 API 權杖的 HMAC/Hash Key         |
| `AUTH_SESSION_IDLE_TTL`                 | `24h`              | Session 閒置限制                      |
| `AUTH_SESSION_ABSOLUTE_TTL`             | `168h`             | Session 最大生命週期                  |
| `AUTH_SESSION_TOUCH_INTERVAL`           | `5m`               | Session Activity Write 最小間隔       |
| `AUTH_SUDO_TTL`                         | `5m`               | 敏感操作的近期驗證有效時間            |
| `AUTH_EXTERNAL_FLOW_TTL`                | `10m`              | OAuth/OIDC Flow 生命週期              |
| `AUTH_PASSWORD_RESET_TOKEN_TTL`         | `30m`              | 密碼重設連結生命週期                  |
| `AUTH_PASSWORD_RESET_RATE_LIMIT_WINDOW` | `1h`               | 密碼重設 Rate Limit Window            |
| `AUTH_PASSWORD_RESET_IP_LIMIT`          | `10`               | 每個 IP 在 Window 內的請求數          |
| `AUTH_PASSWORD_RESET_EMAIL_LIMIT`       | `3`                | 每個 Email 在 Window 內的請求數       |
| `AUTH_ARGON2ID_MEMORY_KIB`              | `65536`            | Argon2id Memory Cost                  |
| `AUTH_ARGON2ID_ITERATIONS`              | `3`                | Argon2id Iteration Cost               |
| `AUTH_ARGON2ID_PARALLELISM`             | `4`                | Argon2id Parallelism                  |

變更 Hash Key 會讓受其保護的憑證失效。

## 背景 Worker

| 變數                                      | 預設值 | 用途                                        |
| ----------------------------------------- | ------ | ------------------------------------------- |
| `ASSIGNMENT_REFRESH_WORKER_ENABLED`       | `true` | 重試佇列中的 Assignment Refresh Job         |
| `ASSIGNMENT_REFRESH_WORKER_INTERVAL`      | `5s`   | Refresh Polling Interval                    |
| `ASSIGNMENT_REFRESH_WORKER_BATCH_SIZE`    | `25`   | 每個 Cycle 取得的 Job 數                    |
| `ASSIGNMENT_REFRESH_WORKER_STALE_TIMEOUT` | `1m`   | 中斷工作重新取得的 Timeout                  |
| `ALERT_EVALUATION_ENABLED`                | `true` | 執行 Alert Evaluation                       |
| `NOTIFICATION_WORKER_ENABLED`             | `true` | 傳送佇列中的事件通知                        |
| `NOTIFICATION_WORKER_INTERVAL`            | `5s`   | Notification Polling Interval               |
| `NOTIFICATION_WORKER_BATCH_SIZE`          | `25`   | 每個 Cycle 取得的 Delivery 數               |
| `NOTIFICATION_WORKER_STALE_TIMEOUT`       | `1m`   | 中斷 Delivery 重新取得的 Timeout            |
| `NOTIFICATION_HTTP_TIMEOUT`               | `10s`  | Webhook、Slack、Discord 與 Telegram Timeout |

停用 Worker 只會暫停工作，不會刪除設定或已排入佇列的 Job。

## Tracing

| 變數                                 | 預設值 | 用途                            |
| ------------------------------------ | ------ | ------------------------------- |
| `OTEL_EXPORTER_OTLP_TRACES_ENDPOINT` | 空白   | OTLP HTTP Trace Ingest Endpoint |

## 探測器代理程式

Installer 會寫入控制器 URL、ID 與 Secret，其餘數值是本機 Tuning Override。

| 變數                                      | 預設值  | 用途                                            |
| ----------------------------------------- | ------- | ----------------------------------------------- |
| `NETSTAMP_PROBE_CONTROLLER_URL`           | 必填    | 控制器 Origin，不含 `/api/v1`                   |
| `NETSTAMP_PROBE_ID`                       | 必填    | 探測器 UUID                                     |
| `NETSTAMP_PROBE_SECRET`                   | 必填    | 探測器 Runtime Secret                           |
| `NETSTAMP_PROBE_HTTP_TIMEOUT`             | `10s`   | Runtime API Request Timeout                     |
| `NETSTAMP_PROBE_MAX_WORKERS`              | `128`   | Concurrent Execution Worker Limit               |
| `NETSTAMP_PROBE_RESULT_QUEUE_SIZE`        | `10000` | Buffered Result Capacity                        |
| `NETSTAMP_PROBE_RESULT_BATCH_SIZE`        | `100`   | 最大 Submission Batch Size                      |
| `NETSTAMP_PROBE_RESULT_FLUSH_INTERVAL`    | `5s`    | Partial Batch 最大等待時間                      |
| `NETSTAMP_PROBE_ASSIGNMENT_TTL`           | `10m`   | 本機 Assignment Freshness Limit                 |
| `NETSTAMP_PROBE_SHUTDOWN_TIMEOUT`         | `10s`   | Graceful Shutdown Deadline                      |
| `NETSTAMP_PROBE_HEARTBEAT_INTERVAL`       | `30s`   | Heartbeat Cadence                               |
| `NETSTAMP_PROBE_ASSIGNMENT_POLL_INTERVAL` | `30s`   | Assignment Polling Cadence                      |
| `NETSTAMP_PROBE_INITIAL_BACKOFF`          | `1s`    | Initial Retry Delay                             |
| `NETSTAMP_PROBE_MAX_BACKOFF`              | `30s`   | Maximum Retry Delay                             |
| `NETSTAMP_PROBE_MAX_ATTEMPTS`             | `5`     | 目前 Retry Cycle 失敗前的 Attempt 數            |
| `NETSTAMP_PROBE_METRICS_ADDR`             | 空白    | 選填 Prometheus Listener，例如 `127.0.0.1:9091` |
| `NETSTAMP_PROBE_PPROF_ADDR`               | 空白    | 選填 pprof Listener，例如 `127.0.0.1:6060`      |
| `NETSTAMP_PROBE_LOG_LEVEL`                | `info`  | `debug`、`info`、`warn` 或 `error`              |

所有數值容量與 Duration 都必須大於零；Maximum Backoff 不得小於 Initial Backoff。

## Web App Build 變數

這些數值會編譯進 Frontend。變更 Container Runtime Environment 不會修改已編譯的 Bundle。

| 變數                                       | 預設值                              | 用途                                |
| ------------------------------------------ | ----------------------------------- | ----------------------------------- |
| `VITE_NETSTAMP_API_BASE_URL`               | `/api/v1`                           | Browser API Base URL                |
| `VITE_NETSTAMP_API_PROXY_TARGET`           | `http://localhost:8080`             | Vite Development Proxy Target       |
| `VITE_NETSTAMP_DEMO_EMAIL`                 | 空白                                | 選填 Demo Login Email               |
| `VITE_NETSTAMP_DEMO_PASSWORD`              | 空白                                | 選填 Demo Login Password            |
| `VITE_NETSTAMP_GOOGLE_TAG_ID`              | 空白                                | Google Tag ID                       |
| `VITE_NETSTAMP_CLARITY_PROJECT_ID`         | 空白                                | Microsoft Clarity Project ID        |
| `VITE_NETSTAMP_META_PIXEL_ID`              | 空白                                | Meta Pixel ID                       |
| `VITE_NETSTAMP_POSTHOG_KEY`                | 空白                                | Public PostHog Project Key          |
| `VITE_NETSTAMP_POSTHOG_HOST`               | `https://us.i.posthog.com`          | PostHog Ingest Host                 |
| `VITE_NETSTAMP_PLAUSIBLE_DOMAIN`           | 空白                                | 回報給 Plausible 的 Domain          |
| `VITE_NETSTAMP_PLAUSIBLE_SCRIPT_URL`       | `https://plausible.io/js/script.js` | Plausible Script URL                |
| `VITE_NETSTAMP_UMAMI_WEBSITE_ID`           | 空白                                | Umami Website ID                    |
| `VITE_NETSTAMP_UMAMI_SCRIPT_URL`           | `https://cloud.umami.is/script.js`  | Umami Script URL                    |
| `VITE_NETSTAMP_TRACKING_CONSENT_MODE`      | `regional`                          | `regional`、`always` 或 `immediate` |
| `VITE_NETSTAMP_TRACKING_CONSENT_COUNTRIES` | 內建區域清單                        | ISO 3166-1 Alpha-2 Country Code     |

舊 Alias `VITE_NETSTAMP_GA_MEASUREMENT_ID` 與 `VITE_NETSTAMP_FACEBOOK_PIXEL_ID` 仍受支援；同時設定時會以新的 Google 和 Meta 名稱為準。所有 `VITE_*` 數值都會公開給瀏覽器，絕對不要放入私密密鑰。

## 文件 Build 變數

| 變數                           | 預設值                     | 用途                    |
| ------------------------------ | -------------------------- | ----------------------- |
| `PUBLIC_SITE_URL`              | `https://netstamp.dev`     | 文件的 Canonical Origin |
| `PUBLIC_NETSTAMP_APP_BASE_URL` | `https://app.netstamp.dev` | 文件中的產品連結        |

文件支援相同的選填 Tracker 與 Consent Control，Prefix 改為 `PUBLIC_NETSTAMP_*`。
