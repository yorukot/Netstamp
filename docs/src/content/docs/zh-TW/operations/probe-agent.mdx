探測器代理程式是單一 Linux Binary，搭配 systemd 服務與執行期排程器運作。

## 安裝的檔案

| 路徑                                         | 用途                                        |
| -------------------------------------------- | ------------------------------------------- |
| `/usr/local/bin/netstamp-agent`              | Agent Binary                                |
| `/etc/netstamp/probe.env`                    | Root 擁有的憑證與控制器 URL，Mode 為 `0600` |
| `/etc/systemd/system/netstamp-agent.service` | systemd Unit                                |
| `/var/lib/netstamp`                          | 專用服務使用者的 Home 與資料目錄            |

服務會以 `netstamp` 使用者與群組執行，只為 ICMP 取得 `CAP_NET_RAW`，並在可行時啟用 `NoNewPrivileges`、私有暫存目錄、受保護 Home 與唯讀 System View 等 systemd 強化設定。

## 檢查狀態與日誌

```bash
sudo netstamp-agent service status
sudo systemctl status netstamp-agent
sudo journalctl -u netstamp-agent -n 200 --no-pager
sudo journalctl -u netstamp-agent --since '30 minutes ago' --follow
```

控制器的探測器詳細資料頁面應顯示近期心跳、版本、位址、能力與上線狀態。

## 重新啟動或安裝新憑證

```bash
sudo systemctl restart netstamp-agent
sudo systemctl is-active netstamp-agent
```

再次執行 `service install` 會更新環境檔與 Unit、重新載入 systemd，並啟用及啟動服務：

```bash
sudo netstamp-agent service install \
  --url 'https://netstamp.example.com' \
  --probe-id '<probe UUID>' \
  --probe-secret '<new secret>'
```

請使用新輪替的 Secret，不要重複使用其他探測器的環境檔。

## 更新 Binary

```bash
sudo netstamp-agent update \
  --url 'https://netstamp.example.com' \
  --api-version 'v1'
```

Agent 會從控制器下載符合主機架構的 Binary、以 Atomic 操作替換已安裝檔案，並在 Unit 存在時重新啟動服務。完成後確認回報的版本與心跳。

## 調校執行期

編輯 `/etc/netstamp/probe.env` 後重新啟動服務。重要選項包括 Worker Concurrency、結果 Queue 與 Batch Size、指派 Polling 與 TTL、Heartbeat Interval、Retry Backoff、Shutdown Timeout 和 Log Level。

完整變數請參閱[設定](/zh-TW/docs/installation/configuration/)。一次只調整一個維度，並觀察佇列、提交、CPU、記憶體與目標負載。

## 啟用 Metrics 與 pprof

兩個診斷 Listener 預設都停用。除非需要受保護的監控網路，否則綁定到 Loopback：

```dotenv
NETSTAMP_PROBE_METRICS_ADDR=127.0.0.1:9091
NETSTAMP_PROBE_PPROF_ADDR=127.0.0.1:6060
```

重新啟動後：

```bash
curl http://127.0.0.1:9091/metrics
curl http://127.0.0.1:6060/debug/pprof/
```

pprof 可能暴露敏感執行期資訊，絕對不要直接公開。

## 解除安裝

若要保留設定與服務使用者，方便之後重新安裝：

```bash
sudo netstamp-agent service uninstall
```

若要一併移除環境檔、資料目錄、使用者與群組：

```bash
sudo netstamp-agent service uninstall --purge
```

解除安裝主機上的 Agent 不會刪除 Netstamp 中的探測器資源。如有需要，請另外停用或刪除該資源。
